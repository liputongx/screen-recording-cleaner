# 📹 录屏文档清洗工具

把「录屏视频」自动变成「干净的 Markdown 文档」。核心流程：

```
上传视频 → 抽帧(可调时间倍率) → 本地开源 OCR 识别 → DeepSeek 清洗 → 导出 Markdown
```

## 功能特性

- **手动控制抽帧时间倍率**：通过「抽帧间隔」控制抽取密度（0.5×/1×/2×/3×/5×/10× 快捷切换，也可精确到 0.1 秒），支持截取视频片段。
- **本地开源识别（默认，免费离线）**：内置 RapidOCR（PaddleOCR 轻量版），中文识别强、免 API Key、不联网，CPU 即可跑。也可切换为云端视觉大模型（通义/智谱/混元/DeepSeek/自定义）。
- **DeepSeek 清洗整合**：识别出文字后，用 DeepSeek（纯文本模型，正好匹配）去重、去噪、合并润色为连贯文档；也提供内置规则清洗（无需 Key）。
- **结果可编辑**：识别、清洗结果全程可见，导出前可直接在页面里编辑。

## 快速开始

### 方式一：双击启动（推荐）

双击 `启动工具.bat`，浏览器自动打开 `http://127.0.0.1:8765`。

### 方式二：命令行启动

```bash
# 首次安装依赖
python -m pip install -r requirements.txt

# 启动
python app.py
```

> ffmpeg 无需手动安装，程序通过 `imageio-ffmpeg` 自动调用内置静态二进制。
> RapidOCR 首次识别时会加载模型（约 1~2 秒），之后复用。

## 使用步骤

1. **上传视频**：点击或拖入录屏文件（mp4/mov/avi/mkv/webm 等）。
2. **抽帧设置**：
   - 「抽帧间隔」即时间倍率——间隔越大帧越少、速度越快；间隔越小内容越密。
   - 可选设置开始/结束时间，只处理片段。
   - 点击「开始抽帧」，下方网格会展示所有帧缩略图，点击可多选/取消选中。
3. **识别引擎**：默认「本地开源 OCR」免 Key 直接点「开始识别」；如需更高精度可切换云端视觉模型并填 Key。
4. **内容清洗**：
   - 「内置规则清洗」：去空、去重、去时间戳/日期噪声，无需 Key。
   - 「DeepSeek 智能整合」：填 DeepSeek API Key 后，让大模型合并润色为连贯文档。
5. **导出**：确认/编辑内容后，点「导出 .md」下载。

## 模型说明

## 常见问题

- **本地 OCR 识别慢**：CPU 逐帧识别，帧越多越慢，可增大抽帧间隔或只识别选中帧。
- **本地 OCR 识别漏字/错字**：受画面清晰度影响，可调小抽帧间隔、或切换云端视觉模型。
- **识别报错 401/403**：API Key 填错或未开通该模型的视觉能力。
- **识别报错 429**：并发过高触发限流，把「并发数」调小到 1~2。
- **抽帧报错**：确认视频文件完整，可尝试先用播放器转成 mp4（H.264）。
- **帧数量过大**：增大「抽帧间隔」（如 3×~5×），或设置片段范围。
